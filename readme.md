This is a student project created for education purposes and is not a real product. Any similarity to real products is purely coincidental.
The content in this assignment, like images and some of the text is inspired by, or generated by LLMs like ChatGPT and Gemini.
The code is written only by myself, although solutions or explanations to a problem may have been provided by LLMs.

The most egregious example of a solution I could not have come up with on my own, is fixing the review cards to look different on mobile. ChatGPT provided a better solution with changing the grid-template for mobile. I had a lot of help from various sources when it came to solving scaling issues on different resolutions. I did not note sources on every website I've read, but the specific solution used here was provided by chatgpt. I did not copy an entire solution, I changed bits of code, one line at a time to see and understand what was happening. min-width: 0 is another example of shameless LLM influence. I've been working backwards with mobile compatibility. In the future I'll be more likely to make a project work on smaller resolutions first.
